# Gemini FreeLLM Android

Minimal Android chat client for a self-hosted FreeLLMAPI server.

Android app → FreeLLMAPI → configured provider (Google AI Studio/Gemini).

Default Base URL: http://127.0.0.1:3001/v1

Enter the FreeLLMAPI Unified API Key in Settings. Never commit an API key to this repository.

GitHub Actions builds a debug APK automatically on pushes to main.
